# Бот для сбора заявок в MAX

Диалоговый бот: пользователь пишет боту в MAX, бот пошагово спрашивает
имя, телефон, город и размер проёма, а готовую заявку присылает вам
личным сообщением и дублирует в файл `leads.jsonl` рядом со скриптом.

## 1. Получить токен бота

1. Зайдите на https://dev.max.ru под своим аккаунтом.
2. Создайте нового бота (имя, юзернейм, аватар — на ваше усмотрение).
3. Скопируйте выданный access-токен.

## 2. Установка и запуск

```bash
cd max-gate-bot
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt

export MAX_BOT_TOKEN="токен_из_кабинета"
python bot.py
```

Бот работает через long polling — отдельный сервер с HTTPS не нужен,
достаточно, чтобы процесс `python bot.py` был постоянно запущен.

## 3. Настроить получателя заявок

1. Найдите вашего бота в MAX и напишите ему любое сообщение.
2. Отправьте команду `/whoami` — бот пришлёт в ответ ваш `user_id`.
3. Остановите скрипт, задайте переменную и перезапустите:

```bash
export ADMIN_USER_ID="полученный_id"
python bot.py
```

Теперь каждая завершённая заявка будет приходить вам личным сообщением
в MAX.

## 4. Как выглядит диалог

```
Бот:  Здравствуйте! Помогу оформить заявку на замер ворот.
      Как к вам обращаться?
Юзер: Алексей
Бот:  Спасибо! По какому телефону с вами связаться?
Юзер: +7 900 123-45-67
Бот:  В каком городе нужны ворота?
Юзер: Тверь
Бот:  Какой примерно размер проёма (в метрах)?
Юзер: метров 4
Бот:  Проверьте заявку: ...
      Всё верно? Напишите «да» — отправим заявку, или «изменить» — заполним заново.
Юзер: да
Бот:  Заявка отправлена! Мы перезвоним вам в течение рабочего дня.
```

Команды: `/start` — начать заново, `/cancel` — отменить текущую заявку,
`/whoami` — узнать свой user_id.

## 5. Чтобы бот работал постоянно

Проще всего — через `systemd` или `pm2`/`screen`/`tmux` на вашем сервере
или VPS, например:

```ini
# /etc/systemd/system/max-gate-bot.service
[Unit]
Description=MAX gate bot
After=network.target

[Service]
WorkingDirectory=/путь/до/max-gate-bot
Environment=MAX_BOT_TOKEN=токен
Environment=ADMIN_USER_ID=ваш_id
ExecStart=/путь/до/max-gate-bot/venv/bin/python bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now max-gate-bot
```

## Примечания

- Публичная документация MAX Bot API периодически меняет названия
  некоторых полей ответа (`camelCase`/`snake_case`). Скрипт написан так,
  чтобы принимать оба варианта (см. функцию `pick` в `bot.py`), но если
  после запуска бот не реагирует на сообщения — посмотрите в консоль:
  туда печатаются сырые ошибки, по ним легко поправить одно-два имени
  поля.
- Для большого потока заявок в проде лучше перейти на webhook
  (`POST /subscriptions` вместо `GET /updates`) — это отдельная
  доработка, скажите, если понадобится.
- Логика диалога и вопросы (имя/телефон/город/размер проёма) — под
  лендинг с воротами. Если нужно собирать другие поля или добавить
  кнопки вместо текстовых ответов — легко расширить.
