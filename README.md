# Bitrix24 Reports Dashboard

Веб-дашборд, показывающий отчёты из Bitrix24 (сделки, лиды, звонки) в реальном
времени через входящий вебхук.

## Настройка

1. Скопируйте `.env.example` в `.env`:
   ```
   cp .env.example .env
   ```
2. Впишите в `.env` URL вашего входящего вебхука Bitrix24
   (CRM → Разработчикам → Другое → Входящий вебхук). Файл `.env` не
   попадает в git — токен вебхука хранится только локально.
3. Установите зависимости и запустите сервер:
   ```
   npm install
   npm start
   ```
4. Откройте http://localhost:3000

## Как это работает

- `server/bitrixClient.js` — вызывает методы REST API Bitrix24 через вебхук
  (с постраничной загрузкой).
- `server/reports.js` — собирает и агрегирует данные: сделки по стадиям,
  лиды по статусу/источнику, звонки по дням (`crm.deal.list`,
  `crm.lead.list`, `voximplant.statistic.get`).
- `server/index.js` — отдаёт статику и endpoint `GET /api/summary?days=30`.
- `public/` — дашборд на чистом JS, опрашивает `/api/summary` каждые 15
  секунд и перерисовывает графики.
- `server/sendLeadsReportToMax.js` — форматирует отчёт по лидам в текстовое
  сообщение и отправляет его в чат мессенджера MAX через
  `POST /api/leads-report/send-to-max` (кнопка «Отправить в MAX» на панели
  «Лиды»).

### Про «реальное время»

Bitrix24 REST API не поддерживает push-уведомления через обычный входящий
вебхук без публично доступного HTTPS-адреса для обратных вызовов. Поэтому
дашборд обновляется через polling (опрос) каждые 15 секунд — с точки зрения
пользователя это выглядит как обновление в реальном времени, но не является
эвент-driven push. Если понадобится настоящий push через события Bitrix24
(`event.bind`), потребуется публичный HTTPS-endpoint для приёма вебхуков.

### Отчёт по звонкам

Использует метод `voximplant.statistic.get`, который требует, чтобы во
входящем вебхуке был включён доступ к разделу «Телефония». Если у вашего
вебхука этого доступа нет, панель «Звонки» покажет ошибку, а остальные
отчёты продолжат работать.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `BITRIX_WEBHOOK_URL` | Базовый URL входящего вебхука Bitrix24 |
| `REPORT_DAYS` | За сколько последних дней собирать данные (по умолчанию 30) |
| `PORT` | Порт HTTP-сервера (по умолчанию 3000) |
